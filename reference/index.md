# Package index

## Places

- [`within_extent()`](within_extent.md) : Search for places within an

  name, address, description, and other attributes
- [`fields`](fields.md) : Possible Fields to Return from Place Details

## Categories

- [`categories()`](categories.md) : Return the name and category ID of
  all categories, or categories which satisfy a filter
- [`category_details()`](category_details.md) : Get the category details
