# Possible Fields to Return from Place Details

A character vector containing the possible return fields that define the
attributes to return. Use in [`place_details()`](place_details.md)'s
`requested_fields` argument.

## Usage

``` r
fields
```

## Format

An object of class `character` of length 40.

<https://developers.arcgis.com/rest/places/place-id-get/#requestedfields>
